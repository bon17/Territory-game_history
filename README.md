# 역사 섬 땅따먹기

중2 역사 기말 복습용 교실 게임입니다. 선생님 노트북 화면을 TV에 띄우고, 학생은 각자 갤럭시탭으로 접속합니다.

- `host.html`: TV 진행 화면
- `play.html`: 학생 탭 화면
- `questions/문제은행_초안.tsv`: 문제은행 (스프레드시트로 열어 고친 뒤 붙여넣기)
- `images/`: 그림을 넣으면 자동으로 바뀌는 자리 (`images/README.txt` 참고)
- `땅따먹기_설계서.md`: 규칙과 화면 설계

## 혼자 미리 해 보기 (데모 모드)

Firebase 설정 전에는 **한 컴퓨터의 브라우저 창끼리만** 연결됩니다.

1. 이 폴더를 [Netlify Drop](https://app.netlify.com/drop)에 끌어다 놓아 주소를 받습니다.
2. `주소/host.html`을 열고 **가상 학생 채우기**를 체크한 뒤 [방 만들기]를 누릅니다.
3. 대기 화면의 [학생 창 열기]를 누르면 학생 화면이 새 창으로 열립니다. 모둠과 번호를 골라 들어갑니다.
4. [시작!]을 누르면 연습 라운드부터 진행됩니다. 가상 학생들이 알아서 답하고 코인을 겁니다.

빨리 확인하고 싶으면 주소 끝에 `?fast`를 붙이세요. 제한 시간이 1/5로 줄어듭니다.

## 실제 수업 (Firebase 연결 후)

`firebase-config.js`에 Firebase 설정값을 붙여넣으면 학생 탭에서 QR코드로 접속할 수 있습니다. 설정 방법은 따로 안내합니다.
